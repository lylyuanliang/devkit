# 从单集群升级到多环境模式

## 概述

Kafka Tool 现已支持多环境管理，允许用户保存和快速切换多个 Kafka 集群配置。本指南帮助您从单集群设置升级到多环境模式。

## 自动迁移

现有的单集群配置会**自动迁移**为 "default" 环境，您无需手动操作：

```
单集群配置
    ↓
自动包装为 "default" 环境
    ↓
继续正常使用（向后兼容）
```

## 手动添加新环境

### 方法 1：使用 UI

1. 打开 Kafka Tool
2. 点击 **"🔧 环境管理"** 面板
3. 点击 **"+ 新建环境"** 按钮
4. 填写以下信息：
   - **环境名称**（唯一标识，如 `production`, `staging`）
   - **Host**（Kafka 集群主机）
   - **Broker 列表**（逗号分隔，如 `kafka1:9092,kafka2:9092,kafka3:9092`）
   - **描述**（可选）

5. 点击 **"创建"** 保存

### 方法 2：配置文件格式

```json
{
  "name": "production",
  "host": "kafka-prod.example.com",
  "brokers": ["kafka-prod-1:9092", "kafka-prod-2:9092", "kafka-prod-3:9092"],
  "connectionConfig": {
    "auth": {
      "mechanism": "plain",
      "username": "kafka-user",
      "password": "secure-password"
    },
    "tls": {
      "enabled": true,
      "caPath": "/path/to/ca.pem",
      "certPath": "/path/to/cert.pem",
      "keyPath": "/path/to/key.pem"
    }
  },
  "description": "Production Kafka cluster in us-east-1",
  "tags": ["production", "critical"],
  "monitoring": {
    "alerting": true,
    "metricsUrl": "https://metrics.example.com"
  }
}
```

## 环境切换

### 快速切换

点击工具头部的 **"🔌 [环境名称]"** 按钮，从下拉菜单选择目标环境：

```
🔌 production ▼
    ├─ ✓ production
    ├─ staging
    └─ dev
```

### 环境切换流程

```
1. 保存当前工作区状态（打开主题、消费者组等）
2. ⏳ 断开旧集群连接
3. 🔄 连接新集群
4. ✓ 恢复该环境的工作区状态
```

切换通常耗时 < 2 秒。

## 工作区状态保留

Kafka Tool 会自动为**每个环境**保留独立的工作区状态：

| 保留项 | 说明 |
|--------|------|
| **打开的主题** | 您上次查看的主题列表 |
| **消费者组** | 已选择的消费者组 |
| **查询历史** | 最后 50 条搜索/查询 |
| **过滤器设置** | Offset、时间范围、关键字等 |
| **UI 偏好** | 视图模式、滚动位置等 |

**示例**：
- 在 `production` 环境查看 `orders-topic`
- 切换到 `staging` 环境查看 `users-topic`
- 切换回 `production` → 自动恢复到 `orders-topic`

## 凭证安全

敏感信息（SASL 密码、TLS 证书）使用 **AES-256-GCM** 加密存储：

### 主密钥

首次使用时自动生成，存储位置：
```
~/.devkit/master.key
```

**重要**：
- ⚠️ 备份此文件以避免丧失对所有凭证的访问
- 🔒 文件权限为 0o600（仅用户可读）
- 🚫 不要与他人分享此密钥

### 密码存储示例

```
✓ 明文存储：环境名称、Host、Broker 列表、描述
🔐 加密存储：SASL 密码、TLS 证书路径、API 密钥
```

## 环境管理操作

### 编辑环境

1. 在环境列表中找到环境
2. 点击 **"编辑"** 按钮
3. 修改所需字段
4. 点击 **"保存修改"**

### 复制环境

快速为相似配置创建新环境：

1. 找到源环境
2. 点击 **"复制"** 按钮
3. 系统将创建 `{name}-copy` 环境
4. 编辑新环境，修改必要字段

### 删除环境

1. 找到要删除的环境
2. 点击 **"删除"** 按钮
3. 确认删除（不可恢复）

## 常见问题

**Q: 迁移后能否恢复到单集群模式？**
A: 是的，只需使用单一 "default" 环境。系统完全向后兼容。

**Q: 切换环境会丢失数据吗？**
A: 不会。工作区状态（主题列表、查询等）会自动保留。数据始终保存在 Kafka 中。

**Q: 密钥丢失了怎么办？**
A: 将生成新密钥。**但旧凭证无法解密**。您需要：
1. 删除旧环境配置
2. 手动重新添加（密钥会重新生成）

**Q: 支持多少个环境？**
A: 理论上无限制。性能不受环境数量影响。

**Q: 能否在多台机器间同步环境？**
A: 暂不支持。凭证绑定到本地主密钥。

## 故障排除

### 连接超时

```
❌ 连接超时: 请检查网络连接和 Broker 地址
```

**解决方案**：
- 验证 Broker 地址和端口正确
- 检查网络连接
- 确认防火墙规则

### 认证失败

```
❌ Broker 不可达: 请检查 Broker 是否正在运行
```

**解决方案**：
- 确认 SASL 用户名/密码正确
- 检查 Kafka 认证配置
- 验证 TLS 证书有效

### 环境不显示

环境列表为空或丢失环境。

**解决方案**：
- 重启 Kafka Tool
- 检查 `~/.devkit/devkit.db` 数据库完整性
- 查看日志了解详细错误
